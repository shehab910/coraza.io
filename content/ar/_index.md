<div class="col-lg-5 mb-4">
  <h3 class="h4">الأمان أولاً</h3>
  <p>طبّق السياسات باستخدام <a href="/ar/docs/tutorials/coreruleset/">OWASP CRS</a> لحظر حقن SQL وXSS وRCE والمزيد — أو اكتب قواعدك الخاصة المخصصة لتطبيقك.</p>
</div>
<div class="col-lg-5 mb-4">
  <h3 class="h4">أداء عالٍ</h3>
  <p>عبء بمستوى ميكروثانية لكل طلب. Coraza مبني بلغة Go للسرعة، ويتعامل مع حركة مرور API عالية الحجم بتأثير ضئيل على زمن الاستجابة.</p>
</div>
<div class="col-lg-5 mb-4">
  <h3 class="h4">قابل للتوسع</h3>
  <p>مُسجِّلات التدقيق ومحركات الاستمرارية والمشغّلات والإجراءات — وسّع Coraza بالإضافات أو أنشئ إضافاتك الخاصة لتناسب أي بنية.</p>
</div>
<div class="col-lg-5 mb-4">
  <h3 class="h4">انشر في أي مكان</h3>
  <p>يعمل كمكتبة أو sidecar أو reverse proxy. يتكامل مع <a href="/ar/connectors/">Caddy وEnvoy وTraefik وNGINX وHAProxy وAPISIX</a> والمزيد.</p>
</div>
<div class="col-lg-5 mb-4">
  <h3 class="h4">مدفوع بالمجتمع</h3>
  <p>مدعوم من OWASP بمجتمع نشط من المساهمين والمستخدمين حول العالم.</p>
</div>
<div class="col-lg-5 mb-4">
  <h3 class="h4">جاهز للمؤسسات</h3>
  <p>مُختبَر في بيئات الإنتاج، موثّق جيداً، ومدعوم بتطوير مستمر وعمليات تدقيق أمني.</p>
</div>
